# Git Demo

A minimal static project. This repository currently contains:

- `index.html`: Simple HTML page with a single heading
- `style.css`: Empty stylesheet ready for customization

## Quick start

- Open `index.html` directly in a browser, or
- Serve the folder with any static server, e.g.:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Documentation

Comprehensive documentation lives in the `docs/` directory:

- `docs/Usage.md`: How to run and work with this project
- `docs/Components.md`: Markup structure and components
- `docs/API.md`: Public APIs and functions (currently none)
- `docs/Examples.md`: Usage examples and patterns

Contributions are welcome. See docs for guidance on adding new components or APIs.
